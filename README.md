#Convergence
💻 A Technical Symposium Website

🔗 Live Demo: https://convergence-one.vercel.app

Convergence is a responsive website developed for a national-level technical symposium. The platform provides students and participants with essential information about the event in an organized and accessible manner.

Features
Technical symposium event information
Event schedules and details
Registration information
Contact information
Responsive design
User-friendly navigation across devices
Purpose

The website provides a centralized platform for participants to explore symposium events, schedules, registration details, and other important information.
